Diotopo is a free software for topology optimization.

It was created by me after several days of searching for a free and good working topology optimization software for 3D printing purposes, that seemed not to exist...

...until now!

It is named and themed after my beloved Eurasier dog Dio.



In the mainfolder you will find 2 folders with available languages:
1. Deutsch
2. English
   
and 5 subfolders with the different systems:
1. Browser Version
2. Portable Version
3. Windows Installer
4. Linux Installer
5. Mac Installer

Its only tested on Browser Version and Windows Installer!
